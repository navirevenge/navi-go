# Roadmap

- **Phase 1 — Foundation** ✅ monorepo, Next.js + Spring Boot, PostgreSQL/Flyway (full schema), Docker Compose, JWT auth, app shell, dashboard, study-session logging, CI.
- **Phase 2 — Learning foundation**: grammar & vocabulary libraries, furigana toggle wired to data, lesson content, study session flow, settings (goal, dialect, furigana/romaji).
- **Phase 3 — AI tutor**: provider-agnostic LLM adapter (OpenAI-compatible + dev mock), conversation orchestration, persisted history, corrections, vocabulary extraction, AI endpoint rate limiting.
- **Phase 4 — Intelligent learning**: FSRS spaced repetition, learner model, adaptive daily plans, analytics.
- **Phase 5 — Voice & production**: STT/TTS interfaces, listening/shadowing, PWA service worker, observability, AWS deployment.
